# CardAuth 易语言 SDK

卡密验证平台易语言 SDK 模块，提供卡密验证、激活、换绑、查询等功能。

## 环境要求

- 易语言 5.9+
- 支持 HMAC-SHA256 加密
- 支持 HTTP 网络请求

## 安装

1. 下载 `卡密验证SDK.ec` 模块文件
2. 在易语言中点击「程序」→「模块引用表」→「添加模块」
3. 选择本模块文件即可

## 快速开始

```易语言
.版本 2

.程序集 窗口程序集_启动窗口

.子程序 _按钮_验证_被单击

    .局部变量 结果, 文本型

    ' 初始化SDK
    初始化SDK (“your_app_key”, “your_app_secret”, “http://your-domain.com”)

    ' 卡密验证
    结果 ＝ 卡密验证 (“CARD-NO-001”, “device-fingerprint”, “My PC”)

    编辑框_结果.内容 ＝ 结果
```

## API 文档

### 初始化SDK

```易语言
初始化SDK (AppKey, AppSecret, BaseUrl)
```

**参数：**
- `AppKey`: 应用 Key
- `AppSecret`: 应用密钥
- `BaseUrl`: API 基础地址（可空，默认为 http://localhost）

### 卡密验证

```易语言
卡密验证 (卡密编号, 设备指纹, 设备名称)
```

验证卡密有效性。

### 卡密激活

```易语言
卡密激活 (卡密编号, 设备指纹, 设备名称)
```

激活卡密并绑定设备。

### 设备换绑

```易语言
设备换绑 (卡密编号, 旧设备指纹, 新设备指纹, 设备名称)
```

更换卡密绑定的设备。

### 卡密查询

```易语言
卡密查询 (卡密编号)
```

查询卡密详细信息。

### 心跳上报

```易语言
心跳上报 (卡密编号, 设备指纹)
```

发送心跳保持在线状态。

### 获取在线人数

```易语言
获取在线人数 ()
```

获取当前在线用户数。

### 获取系统公告

```易语言
获取系统公告 ()
```

获取系统公告信息。

## 返回数据格式

所有接口返回 JSON 格式数据：

```json
{
    "code": 0,
    "message": "success",
    "data": {
        // 具体数据
    },
    "timestamp": 1700000000
}
```

## 签名算法

SDK 内部自动处理签名，签名算法如下：

1. 构造签名串：`METHOD + PATH + TIMESTAMP + NONCE + BODY`
2. 使用 HMAC-SHA256 算法，以 `app_secret` 为密钥对签名串进行加密
3. 签名结果为十六进制字符串（小写）

**请求头：**
- `X-AppKey`: 应用 Key
- `X-Timestamp`: Unix 时间戳（秒）
- `X-Nonce`: 随机字符串（至少8位）
- `X-Sign`: 签名结果

## 错误码

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 4001 | AppKey无效/签名错误 |
| 4002 | 时间戳无效/已过期 |
| 4003 | Nonce无效/重复 |
| 4004 | IP不在白名单 |
| 4101 | 卡密不存在 |
| 4102 | 卡密未激活 |
| 4103 | 卡密已到期 |
| 4104 | 卡密已封禁 |
| 4105 | 卡密已作废 |
| 4106 | 设备绑定超限 |
| 4107 | 应用已停用 |

## 注意事项

1. 本模块为源码示例，需要自行实现 HTTP 请求和 HMAC-SHA256 加密部分
2. 建议配合「精易模块」或其他网络/加密模块使用
3. 时间戳需要使用 Unix 时间戳（秒级）
4. Nonce 建议使用 16 位以上随机字符串
