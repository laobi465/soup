# 宝塔面板部署指南

## 一、环境准备

### 1. 服务器要求
- 操作系统：CentOS 7+ / Ubuntu 18.04+ / Debian 10+
- CPU：2核及以上
- 内存：4GB及以上
- 硬盘：40GB及以上
- 带宽：5Mbps及以上

### 2. 安装宝塔面板
```bash
# CentOS
yum install -y wget && wget -O install.sh http://download.bt.cn/install/install_6.0.sh && sh install.sh

# Ubuntu/Debian
wget -O install.sh http://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh
```

安装完成后，记录面板地址、用户名和密码。

## 二、环境安装

### 1. 登录宝塔面板
访问面板地址，输入用户名密码登录。

### 2. 安装运行环境
在【软件商店】中安装以下软件：
- Nginx 1.25+
- MySQL 8.0
- PHP 8.2
- Redis 7.0
- PM2 管理器（可选，用于前端）

### 3. PHP 扩展安装
在【软件商店】→【PHP-8.2】→【设置】→【安装扩展】中安装：
- redis
- opcache
- fileinfo
- zip
- gd
- bcmath
- pcntl
- intl

### 4. PHP 配置调整
在【软件商店】→【PHP-8.2】→【设置】→【配置修改】中修改：
```ini
upload_max_filesize = 100M
post_max_size = 100M
max_execution_time = 300
memory_limit = 256M
date.timezone = Asia/Shanghai
```

## 三、部署后端

### 1. 创建网站
1. 进入【网站】→【添加站点】
2. 域名：填写后端API域名（如 api.example.com）
3. 根目录：/www/wwwroot/card-auth/server/public
4. PHP版本：选择PHP-8.2
5. 数据库：创建MySQL数据库，记录数据库名、用户名、密码

### 2. 上传代码
```bash
cd /www/wwwroot
git clone <你的代码仓库地址> card-auth
cd card-auth/server
```

或使用宝塔的【文件管理】上传。

### 3. 安装依赖
```bash
cd /www/wwwroot/card-auth/server
composer install --no-dev --optimize-autoloader
```

### 4. 配置环境变量
```bash
cp .example.env .env
vi .env
```

修改以下配置：
```env
APP_DEBUG = false
APP_TRACE = false

[DATABASE]
TYPE = mysql
HOSTNAME = 127.0.0.1
DATABASE = card_auth
USERNAME = root
PASSWORD = 你的数据库密码
HOSTPORT = 3306
CHARSET = utf8mb4
PREFIX = ca_

[CACHE]
DRIVER = redis
HOST = 127.0.0.1
PORT = 6379

[REDIS]
HOST = 127.0.0.1
PORT = 6379
```

### 5. 执行数据库迁移
```bash
php think migrate:run
php think seed:run
```

### 6. 设置目录权限
```bash
chmod -R 755 /www/wwwroot/card-auth/server
chmod -R 777 /www/wwwroot/card-auth/server/runtime
chmod -R 777 /www/wwwroot/card-auth/server/public/static
```

### 7. 配置伪静态
在宝塔面板【网站】→【设置】→【伪静态】中添加：
```nginx
location / {
    if (!-e $request_filename) {
        rewrite ^(.*)$ /index.php?s=$1 last;
        break;
    }
}
```

### 8. 配置SSL证书
在【网站】→【设置】→【SSL】中：
- 可选择 Let's Encrypt 免费证书
- 或上传自己的证书
- 开启【强制HTTPS】

## 四、部署前端

### 1. 构建前端
```bash
cd /www/wwwroot/card-auth/admin
npm install
npm run build
```

### 2. 创建前端站点
1. 进入【网站】→【添加站点】
2. 域名：填写前端域名（如 admin.example.com）
3. 根目录：/www/wwwroot/card-auth/admin/dist
4. PHP版本：纯静态

### 3. 配置 Nginx
在【网站】→【设置】→【配置文件】中添加：
```nginx
location / {
    try_files $uri $uri/ /index.html;
}

location /api/ {
    proxy_pass http://api.example.com/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

### 4. 配置SSL证书
同后端配置。

## 五、配置定时任务

### 1. 数据库备份
在【计划任务】→【添加任务】：
- 任务类型：Shell脚本
- 任务名称：数据库每日备份
- 执行周期：每天 02:00
- 脚本内容：
```bash
#!/bin/bash
BACKUP_DIR="/www/backup/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
mysqldump -u root -p密码 card_auth > ${BACKUP_DIR}/card_auth_${DATE}.sql
gzip ${BACKUP_DIR}/card_auth_${DATE}.sql
find ${BACKUP_DIR} -name "*.sql.gz" -mtime +7 -delete
```

### 2. 队列 Worker
使用 Supervisor 或宝塔【进程守护】：
- 命令：`php /www/wwwroot/card-auth/server/think queue:work --daemon`
- 进程数：2

## 六、安全加固

### 1. 防火墙配置
在【安全】中开放必要端口：
- 80（HTTP）
- 443（HTTPS）
- 22（SSH，建议修改默认端口）

关闭不必要的端口。

### 2. 修改宝塔端口
在【设置】→【安全】中：
- 修改面板端口（如改为 8888 以外的端口）
- 设置面板域名
- 开启 BasicAuth 认证

### 3. 修改 MySQL 端口
在【软件商店】→【MySQL】→【设置】中修改端口，并同步修改 .env 配置。

### 4. 禁用危险 PHP 函数
在 PHP 配置中禁用：
```ini
disable_functions = passthru,exec,system,chroot,chgrp,chown,shell_exec,popen,proc_open,ini_alter,ini_restore,dl,openlog,syslog,readlink,symlink,popepassthru
```

## 七、性能优化

### 1. 开启 OPcache
已在 PHP 扩展中安装，默认开启。

### 2. Redis 缓存
系统配置已使用 Redis 作为缓存驱动。

### 3. 静态资源缓存
在 Nginx 配置中添加：
```nginx
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
    expires 1y;
    access_log off;
    add_header Cache-Control "public, immutable";
}
```

### 4. 开启 Gzip
在 Nginx 配置中添加：
```nginx
gzip on;
gzip_vary on;
gzip_min_length 1024;
gzip_comp_level 6;
gzip_types text/plain text/css text/xml text/javascript application/json application/javascript;
```

## 八、监控与日志

### 1. 监控配置
- 宝塔【监控】可查看服务器资源使用情况
- 建议配置告警规则（CPU、内存、磁盘使用率等）

### 2. 日志管理
- Nginx 日志：/www/wwwlogs/
- PHP 错误日志：/www/server/php/82/var/log/
- MySQL 慢查询日志：/www/server/mysql/data/

## 九、常见问题

### 1. 上传文件失败
- 检查 PHP 配置中 upload_max_filesize 和 post_max_size
- 检查 Nginx 配置中 client_max_body_size
- 检查 storage/logs 中的错误日志

### 2. 页面显示 500 错误
- 查看 runtime/log 下的错误日志
- 检查目录权限是否正确
- 检查 .env 配置是否正确

### 3. 缓存不生效
- 检查 Redis 服务是否运行
- 检查 .env 中缓存配置是否正确
- 检查 PHP redis 扩展是否安装

### 4. 数据库连接失败
- 检查 MySQL 服务是否运行
- 检查 .env 中数据库配置
- 检查数据库用户权限
